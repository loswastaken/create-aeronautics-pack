# Create Aeronautics pack

packwiz pack for Los's server: Minecraft 1.21.1, NeoForge 21.1.265, Create, Sable, Create Aeronautics (all from Modrinth). Links only, no mod files.

## Join with Prism Launcher
1. Create an instance: Minecraft 1.21.1, NeoForge 21.1.265 (Java 21).
2. Edit instance > Settings > Custom commands > Pre-launch command:
   `"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/loswastaken/create-aeronautics-pack/main/pack.toml`
3. Download https://github.com/packwiz/packwiz-installer-bootstrap/releases/latest/download/packwiz-installer-bootstrap.jar into the instance's `.minecraft` folder.
4. Launch. Mods sync on every launch.
